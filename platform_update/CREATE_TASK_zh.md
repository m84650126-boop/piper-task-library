## 示例：创建“推圆柱到目标”

1. 点击“新建原子任务…”，在“名称与动作模板”页选择“桌面推送 · 配置变体”。
2. 填写任务ID `push_cylinder_demo`、显示名称“推圆柱到目标”、作者。ID只能使用小写字母、数字和下划线，首位为字母；不能重复。
3. 训练指令可填 `Push the cylinder into the green target area, then disengage.`。留空时沿用模板指令，平台会按所选物品替换默认 red cube 名称。
4. 切换“场景与随机范围”页，场景选择 robosuite 实验室桌台；物品选择“圆柱体 · 直立”。
5. 先保留向导给出的推送默认坐标和区域：起点 `[0.36,-0.10]`、目标 `[0.46,-0.10]`，位移10cm。
   起点范围 `0.32,0.38,-0.13,-0.07`，目标范围 `0.42,0.48,-0.13,-0.07`，最小距离 `0.06`。
   单位是米。采样时还会过滤不满足方向、距离或可达性的条件。
6. 勾选“创建并启用”，点击“创建任务与任务包”。成功提示会给出源码与ZIP路径。
7. 关闭并重新启动工作台，在顶部任务列表选择“推圆柱到目标”。任务保存的场景、物品和区域会作为默认设置。
8. 点击“按当前摆放执行专家 · 录制1条”，观察动作，再检查/预览。成功后按需要设置数量并启动批采。
9. 审核失败样例、空间覆盖和物理回放；导出训练数据还需满足固定训练/验证/测试空间组覆盖。

创建任务时只是检查了参数与采样范围，不等于整片区域都可达，也不等于专家或学习策略已经验证。

## 哪些设置可以不写代码

当前向导可基于四个模板创建命名明确的配置变体：

| 模板 | 可调整 | 保留的行为与边界 |
|---|---|---|
| 完整拾放 | 已有场景、已有物品、起点/目标与范围 | 原拾放专家、朝下抓取与完整成功判据 |
| 桌面推送 | 同上 | 沿世界+X±30°，距离6～16cm，桌面推送并退开 |
| 夹持桌面拉回 | 同上 | 沿世界−X±30°，距离6～16cm，夹持、近桌面拉回、释放 |
| 桌面擦拭 | 场景、带起点/终点与范围 | 现有刚性擦拭垫和覆盖判据，工具已安装；不模拟污渍清除 |

变体沿用模板的阶段、控制器和成功判据。重命名不产生新控制能力，不自动拆出可靠独立的 grasp/place 接口。
新网格、新容器、新工具或全新动作逻辑目前仍需开发场景与控制代码，向导不是任意任务的无代码编程器。

## 全新动作逻辑怎么做

选择“全新动作逻辑 · 开发草稿（需编程）”。向导会生成源码、配置、清单和任务包，**不会自动启用草稿**。
编辑 task.py，替换待实现函数：环境构造、独立启动条件、专家规划、动作生成、纯数据成功判据。
task.py里已有三个阶段按钮的基本接口；具体说明见 TASK_PLUGIN_API_zh.md。
将新增模型/纹理放在同一个任务目录的 assets 下，使用可迁移路径并附来源许可。
可参考 examples/shared_reach：其中有真实的场景JSON、MJCF和纹理装配及物理成功判定。
完成后重新seal/export，再从“任务共享 → 检查 / 安装任务包”明确启用。

## 文件在哪里、如何修改与分享

以任务ID push_cylinder_demo 为例：

```text
task_sources/push_cylinder_demo/1.0.0/       可编辑源码
  task.py                                 入口；配置变体调用平台模板适配器
  scene.json                              名称、指令、模板和默认场景参数
  task_package.json                       作者、版本、校验清单
  README.md
  LICENSE.txt
task_sources/push_cylinder_demo/push_cylinder_demo_1.0.0.zip
task_packages/push_cylinder_demo/1.0.0-哈希/ 已安装的固定版本
```

编辑源码目录，不要直接修改已安装目录。修改已发布内容应复制为1.0.1目录，同时更新scene.json和task_package.json版本。

```powershell
.\.venv\Scripts\python.exe platform_cli.py packages seal task_sources\push_cylinder_demo\1.0.1
.\.venv\Scripts\python.exe platform_cli.py packages export task_sources\push_cylinder_demo\1.0.1 --output task_sources\push_cylinder_demo\push_cylinder_demo_1.0.1.zip
```

也可通过“任务共享 → 从任务源目录导出…”导出已seal的源码目录。
ZIP可直接发给同事安装；发布到Git共享库时需提交源码、包和验证记录，创建向导不会自动上传。
请保留旧版；回放旧数据时启用数据记录的原任务版本。

## 常见情况

- 找不到新建按钮：关闭旧窗口后重启，正在运行的旧进程不会自动更新界面。
- 创建后任务列表未更新：启用配置在重启时加载；先安全结束录制或批采，再重启。
- 配置被拒绝：检查固定点和随机范围，推拉方向及6～16cm距离限制。不要通过改名称绕过限制。
- 创建成功但专家失败：配置检查不是物理成功保证，缩小范围或修正任务实现后重新验证。
- 草稿不能采集：这是预期状态，先完成控制逻辑和成功判据。
