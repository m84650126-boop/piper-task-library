# PiPER-L 原子技能采集说明

本次更新沿用交接包的 MuJoCo 工作台。安装、场次管理、双相机录制、回放、任务包和 LeRobot 导出共用原平台入口。完整拾放与现有模型评测入口继续可用。

## 启动和采集

安装完整平台后执行 `python setup_platform.py`，Windows 使用 `start_workbench.cmd` 启动。工作台顶部打开「技能目录…」，按中文、英文或分类搜索。选中可采集任务后点「打开采集任务」，查看说明，再点「按当前摆放执行专家 · 录制1条」。在轨迹列表中选中结果可回看双相机并执行「检查」。批采前先用默认坐标试录一条，随后设置随机区间、seed 和数量。旋钮的手动控制使用 Q/E，步长为 5°。

原交接 ZIP 的打包规则漏收了 robosuite 的 `models` 子目录。若从该 ZIP 安装，可执行 `python install_scene_assets.py` 按锁定提交补齐资产，再运行 `platform_cli.py doctor --physics --render`。修正后的完整离线包已包含这些文件。Git 共享库沿用代码更新方式，基础机器人及 robosuite 资产从完整平台取得。

```powershell
.\.venv\Scripts\python.exe platform_cli.py skills
.\.venv\Scripts\python.exe platform_cli.py collect --task open --episodes 1
.\.venv\Scripts\python.exe platform_cli.py collect --task shake --episodes 1
```

输出保存在 `data/workbench/session_*/raw`，也可通过 `PIPER_WORKBENCH_DATA` 指向其他目录。默认记录固定相机和腕部相机，分辨率 320 × 240，20 Hz。状态和动作都保留 6 个关节值与总夹爪开度，动作采用绝对目标。使用 `--diagnostics-only` 可关闭图像，用于物理调试。

## 可采集范围

| 技能 | 任务 ID | 初始状态与成功证据 |
| --- | --- | --- |
| 抓取 | `pick` | 从桌面空爪开始，抓起物体并在起点上方保持稳定。 |
| 移动 | `move_held_object` | 从真实接触预抓取得到已夹持状态。持物到达绿区上方，全程维持夹持。 |
| 放置 | `place` | 预抓取并移动到目标上方后开始录制。释放后物体由桌面承载，在目标内稳定，夹爪退开。 |
| 摇晃 | `shake` | 从已夹持状态开始。物体沿世界 Y 轴交替达到两侧至少 32 mm 的偏移，共六次到侧，返回起点附近，全程保持夹持。 |
| 打开和关闭 | `open`、`close` | 夹持滑盖把手沿导轨运动，在另一端释放。检查行程、接触力及最终稳定。 |
| 按压 | `press` | 夹指按下弹簧按钮，抬离后按钮回弹。 |
| 旋转 | `rotate` | 夹持有机械限位的旋钮，顺时针转动约 60° 后释放。 |
| 推移和拉动 | `push`、`pull` | 分别为桌面接触推送和夹持后桌面拉回。 |
| 擦拭 | `wipe` | 使用预装擦拭垫，检查接触覆盖。 |

图中共有 29 个具名技能。「全部通用技能」是筛选项，「未归类」是分类标签。目录列出的待实现技能缺少可录制的物理场景或可重算的成功判据。当前范围包括 11 个具名技能，另外保留完整拾放和扩展示例。待实现的 18 项为交接、旋拧、插接、倾倒、填充、舀取、搅拌、浸蘸、折叠与展开、系结、扫拢、清洗、刷拭、切割、剥皮、敲击、扫描和抛掷。

## 资产和数据边界

抓取类任务沿用 PiPER-L 网格、夹指接触模型及 robosuite 物品选项。滑盖、按钮和旋钮是本项目参数化 MJCF 工装。滑盖关节行程 70 mm，设有关节摩擦及阻尼。按钮行程 14 mm，弹簧刚度 650 N/m。旋钮限位 60°，设有惯量、摩擦和阻尼。工装只在重置时设置初始位置，运行中由夹指通过接触驱动。工装质量、摩擦和弹簧系数为仿真设定，精度验证限于此几何及物理参数。

录制时保存工装关节位置、速度和 20 Hz 采样点的夹指法向力。审核会重算成功判据，并用保存的动作和积分状态核对物理回放。工装法向力用于任务筛查，瞬态冲击峰值需要更高采样频率。放置任务的空间分组以录制首帧的物体位置和目标位置为准，采集配置中的物体坐标指预抓取前的位置。

LeRobot 导出继续使用原工作台流程。训练前按 [平台使用手册](USER_MANUAL_zh.md) 检查导出读回结果和空间划分。模型闭环评测沿用原有完整拾放范围。
