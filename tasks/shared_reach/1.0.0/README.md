# 共享到达目标示例

此任务演示完整共享包：task.py、scene.json、MJCF 资产及 PNG 纹理一起迁移。
复用平台内的 PiPER-L 和 robosuite 桌台资产，接收者需安装支持任务包 v1 的平台。
空载 TCP 到目标上方 18 cm，稳定至少 0.5 s，参考物体不得触碰/移动超过 5 mm。
专家控制器的成功不代表训练策略已通过独立启动或连续技能交接验证。

复制此目录，修改任务 id、版本、代码与配置，再运行 packages seal 和 packages export。
纹理与 marker.xml 为本示例生成；未包含用户轨迹、权重或外部下载资产。
代码和配置变更应升级版本；请给实际新增资产记录来源与许可。
